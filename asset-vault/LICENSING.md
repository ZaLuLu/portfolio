# Asset and Component Licensing Register

This file is an operational checklist, not legal advice. Verify the live terms at the time an asset is downloaded and before deployment.

## Important known notes

### OriginKit
OriginKit's published licensing page describes a worldwide, non-exclusive, royalty-free, perpetual licence to use, modify and incorporate obtained components into projects, subject to restrictions. It distinguishes building/operating one's own project from distributing or selling the component itself. Read the current full terms and component availability before use.

### ReactBits
The repository currently describes its licence as MIT + Commons Clause and notes third-party notices for certain adapted effects. Read the actual repository licence and notices for the selected component. Do not assume every third-party dependency or asset shares the same licence.

### ShaderGradient
Check repository/package licence and current npm package metadata before copying source or redistributing anything. Prefer normal package installation where appropriate.

### Liquid Logo
Check repository `LICENSE` and notices at the exact commit used. Keep attribution and licence file if required.

### Poly Haven
Poly Haven states its HDRIs, textures and 3D models are CC0. Attribution is not required under that licence, but credit is appreciated.

### Khronos glTF Sample Assets
Each model directory includes its own licence and credit information. Check the selected model's own README. The collection is not one uniform licence.

### awesome-3d-assets
This is a curated directory. Its own CC0 dedication applies to its list and original writing, not to every linked third-party asset.

### pmndrs examples
Check repository licence and per-example asset credits. Example code being MIT does not automatically relicense linked images, models or textures.

### GSAP
Check the current GSAP licence and usage terms before use. Do not rely on old assumptions about its free/commercial licensing.

### Fonts
Font licences are separate from code licences. Verify desktop/web embedding rights, self-hosting rights and redistribution terms for each font.

## Required record per imported asset

- Asset name and local path.
- Original source URL.
- Author / creator.
- Exact licence and source file URL.
- Commit hash or download date.
- Required attribution.
- Modifications made.
- Intended use.
- Whether the asset can be redistributed in this repository.

No asset enters production without this record.

# Wafiq Personal Brand Kit

**Identity direction:** Crimson-led editorial identity  
**Palette:** Crimson, Coral, Plum, Sand, Canary Yellow  
**Version:** 1.0

## Start here
1. Read `01_Brand_Guidelines/Brand_Guidelines.md` for practical brand rules.
2. Read `01_Brand_Guidelines/Colour_Psychology_and_Combination_Guide.pdf` for researched colour associations, recommended combinations, caveats and sources.
3. Use the SVG files in `02_Logo_Assets/SVG` for websites, design tools and print.
4. Use PNG exports in `02_Logo_Assets/PNG` where raster assets are needed.
5. Use `03_Favicons/favicon.ico` or the PNG sizes for web/app icons.

## Official colours
- Crimson `#EB0E31` — RGB 235, 14, 49
- Coral `#FDA2AC` — RGB 253, 162, 172
- Plum `#33212C` — RGB 51, 33, 44
- Sand `#D8CFC2` — RGB 216, 207, 194
- Canary Yellow `#E7C75A` — RGB 231, 199, 90

## Logo notes
The original SVG and PNG supplied by the user are preserved in `04_Reference`. Recoloured SVG variants were generated from the traced SVG by mapping dark path fills to the target foreground and light path fills to white. The W mark has not been redrawn. Review the variants at intended sizes before public release, especially the favicon.

The supplied `W.png` is a white-background reference rather than a transparent PNG. The SVG is the scalable master candidate.

## Colour psychology note
The PDF distinguishes peer-reviewed findings from brand-design interpretation. Colour associations are context-dependent and should not be treated as universal behavioural effects.
